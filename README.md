# Crosshair Indicator (`crosshair_indicator`)

A native Horizon mod (`horizon-mixins` bundle) by **CayMac** that ports the popular Java **Crosshair Indicator** (AmerDz01) mod into Horizon:

- 🎯 **Dynamic Attack Range Feedback**: Visually alerts you the instant an enemy or mob is within true attack range ($\le 3.0$ blocks), ensuring your hits always connect.
- ⚡ **Charge & Weapon State**: Intelligently switches colors based on weapon charge (e.g. green when fully charged and ready for 100% damage, orange/red when still charging).
- 🎨 **4 Indicator Styles**:
  - `Brackets [ + ]`: Four sleek tactical corner markers around the crosshair.
  - `Center Dot ·`: A crisp indicator dot in the crosshair gap.
  - `Diamond ◆`: 4 accent pips at the crosshair extremities.
  - `Chevron ▼`: Tactical target pointer above the crosshair.
- 🌈 **Multiple Color Themes**: Dynamic (Green/Orange), Combat Red, Pink Aesthetic, Diamond Cyan, and Gold.
- ⚙️ **In-Game Settings**: Configure all options in real-time under *Options > Mods > Crosshair Indicator*.

## Controls
- **Toggle Mod**: Default `key.keyboard.unknown` (bindable in Options > Controls / Mods).
